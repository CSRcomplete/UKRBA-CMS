# Sending 5GBP assessments to the CRM

Endpoint: `POST https://crm.ukrba.org/api/v1/webhooks/wix-assessments?token=<WIX_WEBHOOK_TOKEN>`
(or `Authorization: Bearer <token>`). Keep the token in **backend** code only (Wix `.web.js` /
Railway env), never in page code — page code is visible in the browser.

Every submission is identified by a `submission_id` generated by the Wix page. The endpoint is
called **twice** with the same `submission_id` and merges both calls into one row, in either order:

| Call | From | Sends |
| --- | --- | --- |
| 1 | Wix (on submit) | answers + business/contact details |
| 2 | Railway (when the report is built) | `report_url` |

The CRM links the row to the existing lead by email (then business name + postcode), so the lead's
RD and AD see it under **Assessments**.

## 1. Wix backend — `backend/UKRBA.web.js`

```js
import { fetch } from 'wix-fetch';

const CRM_ASSESSMENTS_URL = "https://crm.ukrba.org/api/v1/webhooks/wix-assessments";
const CRM_TOKEN = "<WIX_WEBHOOK_TOKEN>"; // ideally from wix-secrets-backend

export async function sendAssessmentToCRM(payload) {
  try {
    const res = await fetch(`${CRM_ASSESSMENTS_URL}?token=${CRM_TOKEN}`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
    });
    return await res.json();
  } catch (err) {
    return { error: err.message };
  }
}
```

## 2. Wix page code

Import it alongside `syncLeadToCRM`:

```js
import { saveFivePoundFormData, syncLeadToCRM, sendAssessmentToCRM } from 'backend/UKRBA.web.js';
```

Generate the id right after `formData` is built (so Railway receives it too, because `aiPayload`
spreads `formData`):

```js
formData.submission_id = `${Date.now()}-${Math.random().toString(36).slice(2, 10)}`;
```

Then, **after** the `syncLeadToCRM` try/catch block and before `$w("#submit").label = "Generating..."`:

```js
try {
  const answers = { url: formData.url, describeBusiness: formData.describeBusiness };
  questions.forEach(num => { answers[`q${num}`] = formData[`q${num}`]; });

  await sendAssessmentToCRM({
    submission_id: formData.submission_id,
    assessment_type: "5GBP Free Assessment",
    business_name: formData.business_name,
    contact_name: formData.namePolicyOwner,
    email: formData.email,
    phone: formData.phone,
    postcode: formData.postcode,
    website: formData.url,
    membership_number: formData.membershipNumber,
    referred_by_rd: refId,
    answers,
  });
} catch (e) {
  console.error("Assessment sync to CRM failed:", e);
}
```

## 3. Railway app — after the report link exists

Use the `submission_id` that arrived in the `/api/submit-form` body:

```js
await fetch(`https://crm.ukrba.org/api/v1/webhooks/wix-assessments?token=${process.env.CRM_WEBHOOK_TOKEN}`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    submission_id: body.submission_id,
    email: body.email,
    report_url: reportUrl, // the link you email to the client
  }),
});
```

If the report fails, send `{ submission_id, report_status: "failed" }` instead.

## Notes

- Pending-report rows show a "Generating" badge in the CRM until `report_url` arrives.
- Assessments that match no lead are saved with no lead attached and are visible to
  admin/CEO/COO/ops/manager roles only (flagged **Unmatched**).
- Question wording for `q4…q30` lives in `lib/assessment-questions.ts`; add the real labels there.
